# Проверки версии 0.2 — 8 октября 2026

Локальная проверка на синтетических данных:

- Java unit/integration tests: проходят, включая OpenAPI 3.0/3.1, полный Rental-каталог, JSON Schema, выбор операции в два этапа, изоляцию владельцев и проекцию ответа.
- JDBC на H2 и PostgreSQL 16: сохранение после перезапуска, CAS между экземплярами, квоты, шифрование, audit, UNKNOWN после прерванной попытки, аннулирование подтверждения при смене контракта.
- React: 7 тестов, TypeScript build и npm pack проходят; восстановление ID сессии, подтверждение, отмена, неопределённый результат, устаревшее подтверждение.
- DeepSeek: opt-in LiveProviderTest с полным каталогом 19 разрешённых операций прошёл. Сбор недостающего телефона, валидный предпросмотр, явное подтверждение и один REST-вызов на локальную заглушку.
- Rental Management: OpenApiContractTest проверяет все 66 операций контроллеров и snapshot; 19 включены. Backend test/package и frontend build проходят.
- Сквозной Rental smoke-test с настоящей PostgreSQL: Flyway V1–V10, аутентификация, невалидный email, сохранение неподтверждённой сессии после рестарта, конкурентные подтверждения, один созданный арендатор, повтор после второго рестарта, изоляция аккаунтов и чтение списка.
- Docker backend (Java 21) и frontend собираются. Исходники vendored-библиотеки и контракта сверены с основным репозиторием.
- npm audit после обновления source-map-js и Vitest: 0 известных уязвимостей в проверенных npm-зависимостях. Это не полный аудит безопасности всей системы.
- Проверка файлов и npm-архива на шаблоны API-ключей и приватных ключей: совпадений нет. Реальный ключ остаётся в игнорируемом локальном env-файле.

Сквозной тест сохранён в Rental Management как `scripts/test-text-agent.py`, подключён к CI с отдельной PostgreSQL. Текущий production-сервер этими проверками не обновлялся.

Пределы результата: единичный живой smoke-test не заменяет оценку качества языка; нагрузочное тестирование и staging на копии рабочих данных ещё необходимы. CAS не гарантирует exactly-once бизнес-транзакцию. Маскирование перед облачной моделью не реализовано по согласованному объёму работ.
